02 — Work

Work, one row at a time

Three stops, newest first. Open a row for the detail.

  1. 2024 — 2026 Fractal Analytics Built an enterprise LLM gateway that gives teams one entry point to several model providers, with usage tracking and cost governance, and designed the backend of an enterprise AI catalog.

    The gateway runs on Kubernetes and sits in front of several model providers. It handles millions of daily requests, with routing overhead under 20 ms at p95, and keeps per-team usage and cost visible to the people paying for it.

    The catalog's backend indexes internal models and datasets, so teams can see what already exists before building it again. The client is a large U.S. healthcare enterprise, which is as specific as I can get.

  2. 2023 — 2024 Avananta Innovations Built conversational AI systems at an early-stage startup and spent a lot of time on how quickly they responded.

    The team was small, so the work moved between design, code and deployment, usually in the same week.
